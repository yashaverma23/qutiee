# 💖 Propose Day – Valentine Website 💍

A cute, romantic, and interactive proposal website built with **HTML, CSS, and JavaScript**.  
Designed especially for **Propose Day / Valentine’s Day**, with a fun flow, animations, and surprises 💌

---

## 🌹 Live Flow of the Website

1. **Intro Page (`index.html`)**
   - Cute GIF
   - Typing animation
   - Playful “Yes / No” buttons
   - Floating hearts animation 💖

2. **Letter Page (`begin.html`)**
   - Animated envelope ✉️
   - Click to open the letter
   - Love letter appears with typing effect
   - “Next” button after the message completes

3. **Proposal Page (`next.html`)**
   - Proposal image (boy on knees 💍)
   - Question: *“Will you be my Valentine?”*
   - YES button → celebration 🎉
   - NO button runs away with changing messages 😏

4. **Celebration Page (`last.html`)**
   - “She said YES!!!” 🎉
   - Confetti animation
   - Final heartfelt message 💖

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3 (Mobile-first & Responsive)**
- **Vanilla JavaScript**
- **No backend**
- **No external libraries**

✔ Fully compatible with **GitHub Pages**  
✔ Works on **mobile, tablet, and desktop**
